HOW TO GET YOUR .geode (no installs needed)

1. Make a free account at github.com and create a NEW repository (any name, can be private).
2. Click "uploading an existing file", then drag in everything from this folder
   (including the hidden .github folder - if you can't see it, use the zip's contents,
   or upload via GitHub Desktop). Commit.
3. Open the repo's "Actions" tab. A "Build Binaries" run starts automatically (~5-10 min).
4. When it's green, open the run and download "Build Output" at the bottom.
5. Unzip it and take rebal.chaosmod.geode.
6. Put the .geode in:  <your GD folder>\geode\mods\   (this requires Geode installed in your game)
   Or in GD: Geode menu -> Mods -> the "+" / drag the file in, then restart the game.

If the build fails, copy the error text from the Actions log and send it to Claude.
